## 2. Classification Key

- **COMPLETE**: Fully wired, real backend data stream, verified end-to-end on target device via ADB.
- **PARTIAL**: Backend endpoints confirmed and functional; Android screen exists but retains static demo cards/values that require live StateFlow binding.
- **MISSING_BACKEND**: Required by Claude specification but missing from Hermes server (none discovered; Hermes already implements all necessary subsystems).
- **MISSING_CLIENT**: Backend exists, but Android client has no corresponding UI component yet.
